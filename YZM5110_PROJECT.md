

\# YZM5110 — Robust Self-MM



Research project based on THUIAR/MMSA.



\## Research Topic

Robust Multimodal Sentiment Analysis under Missing and Corrupted Modalities.



\## Base Model

Self-MM (AAAI 2021)



\## Proposed Improvement

Reliability-weighted fusion using unimodal prediction consistency and modality dropout.



\## Dataset

CMU-MOSI (unaligned\_50.pkl)



The dataset must be downloaded separately from the official MMSA resources.



\## Development Environment

\- Windows 11

\- NVIDIA RTX 3050 Ti Laptop GPU (4 GB)

\- Python 3.10.5

\- PyTorch 2.3.1 + CUDA 12.1

\- MMSA 2.2.1
